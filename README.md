# Project1 - A Game Project

A Unity-based game project featuring advanced shader programming and graphics rendering.

## 📋 Description

This is a game development project built with Unity, showcasing shader-intensive graphics and visual effects programming.

## 🛠️ Tech Stack

- **Primary Language**: ShaderLab (79.4%) - Unity shader language
- **Shaders**: HLSL (13.8%) - High-Level Shader Language
- **Scripting**: C# (6.8%) - Game logic and mechanics

## 📁 Project Structure

```
Project1/
├── Assets/              # Game assets (textures, models, shaders, prefabs)
├── Packages/            # Unity package dependencies
├── ProjectSettings/     # Unity project configuration
└── README.md           # This file
```

## 🚀 Getting Started

### Prerequisites
- Unity (version TBD - check ProjectSettings for details)
- Git

### Installation

1. Clone the repository:
```bash
git clone https://github.com/S0HAM03/Project1.git
cd Project1
```

2. Open the project in Unity:
   - Launch Unity Hub
   - Click "Open Project"
   - Select the `Project1` folder

3. Wait for Unity to import assets and compile shaders
